# Xet Garbage Collection Implementation Plan

> **For agentic workers:** Execute natively with superpowers:executing-plans (the session
> implements every task itself; subagent-driven development is not used in this project).
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `sghub gc xet` deletes xet file records and xorbs that no existing repository holds,
run unattended by a Kubernetes CronJob from the hub chart.

**Architecture:** Two-phase deletion through parked KV keys with a three-state lifecycle
(`parked` → `restoring` | `deleting`) guarded by compare-and-set. `pkg/xet/store` owns the
key lifecycle; the request paths (xorb upload, shard registration, link, reads) restore parked
data on demand through it; `pkg/xet/gc` runs the sweep; `cmd/sghub` wires it; `helm/` ships
the CronJob.

**Tech Stack:** Go 1.24, `pkg/kv` (Get/SetIf predicates), block adapters, cobra, Helm.

**Spec:** `docs/superpowers/specs/2026-10-26-xet-gc-design.md`

## Global Constraints

- Liveness is ref-based: a file is held while any file ref names it; a xorb is used while any
  live file record has a segment in it. Nothing walks commits.
- Parked keys: `xet/gc/file/<file hash>`, `xet/gc/xorb/<xorb hash>`; value JSON
  `{"state": "parked"|"restoring"|"deleting", "parked_at": <unix seconds>, "data": <bytes, base64>}`.
- File records are deleted `xet.gc.min_age` (default `24h`) after parking; xorbs
  `xet.gc.xorb_min_age` (default `168h`) after parking. Parking needs file `registered_at` /
  xorb object last-modified older than `xet.gc.min_age`.
- `xet.gc.scan_batch_size` default `1000`; the `xet.read` config section is removed.
- Request paths never delete a file ref and never answer 404 because of GC; an upload that
  meets a `deleting` xorb answers 503.
- A file ref is deleted by the sweep only when its repository is reported not found.
- Each scan that builds the held or used set aborts the run on error.
- `--dry-run` performs no KV or blockstore write (it also takes no lock).
- Style: match `pkg/xet/store/register.go` and neighbours; gofmt; no legacy branches; no plan
  or task numbers in code, comments or commits; conventional commits via `/usr/bin/git`,
  staging named files only, no Co-Authored-By trailer.
- Tests: run only the packages a task touches while iterating; the broad suite runs once at
  the end (Task 6).

## Review Focus

- A repository lookup that fails with anything other than not-found (KV hiccup) must keep the
  ref → test in Task 3.
- File records written before this change have no `registered_at` (zero) and count as old →
  test in Task 1.
- A blockstore without a walker (`ErrOperationNotSupported`) or a listing error must stop the
  xorb steps, not treat every xorb as absent → test in Task 3.
- A parked file whose xorbs are also parked, linked again between runs, must read correctly
  (file restored by the link, footer restored by the read) → test in Task 2.
- A second concurrent run (manual run while the CronJob runs) must refuse to start → test in
  Task 3.

### Task 1: Parked key lifecycle and listings in the registry

**Files:**
- Create: `pkg/xet/store/parked.go`, `pkg/xet/store/parked_test.go`
- Modify: `pkg/xet/store/shard_format.go` (`ShardFileInfo`), `pkg/xet/store/register.go`,
  `pkg/xet/store/register_test.go`, `pkg/xet/gc/gc.go` (only to compile against renamed
  listings)

**Interfaces — Produces:**
- `ShardFileInfo.RegisteredAt int64` (`json:"registered_at,omitempty"`); `RegisterFile` sets
  it to `time.Now().Unix()` when zero.
- `func (r *Registry) ListFiles(ctx, batchSize int) ([]ShardFileInfo, error)` (replaces
  `ListFileHashes`); `func (r *Registry) ListXorbFooterHashes(ctx, batchSize int) ([]string, error)`;
  `func (r *Registry) DeleteFileRef(ctx, ref FileRef) error`.
- `type ParkedKind string` with `ParkedFile = "file"`, `ParkedXorb = "xorb"`;
  `type ParkedState string` with `StateParked`, `StateRestoring`, `StateDeleting`;
  `type Parked struct { State ParkedState; ParkedAt int64; Data []byte }` (JSON names from the
  constraints).
- `func (r *Registry) Park(ctx, kind ParkedKind, hash string, now time.Time) (bool, error)` —
  copy the live value into a new parked key (create-only), then delete the live key; false if
  there is no live value or a parked key already exists.
- `func (r *Registry) ParkOrphanXorb(ctx, hash string, now time.Time) (bool, error)` — parked
  key with no data, create-only.
- `func (r *Registry) ListParked(ctx, kind ParkedKind, batchSize int) (map[string]Parked, error)`.
- `type RestoreResult int` with `NotParked`, `Restored`, `Deleting`.
- `func (r *Registry) Restore(ctx, kind ParkedKind, hash string, rebuild func() ([]byte, error), claimOrphan bool) (RestoreResult, error)`:
  `parked` → `SetIf` to `restoring` (predicate = read value), write the live key create-only
  from `Data` (or `rebuild()` when `Data` is empty), delete the parked key; `restoring` →
  finish the same way; `deleting` → `Deleting`; no parked key → `NotParked`, unless
  `claimOrphan`, in which case create a `restoring` key create-only, `rebuild()`, write live,
  delete the parked key. A lost `SetIf` re-reads and retries once.
- `func (r *Registry) DeleteParked(ctx, kind ParkedKind, hash string, removeObject func() error) (bool, error)`:
  `parked` → `SetIf` to `deleting`; `deleting` → continue; then `removeObject()` (nil allowed)
  and delete the parked key; `restoring` or lost `SetIf` → false.
- `func (r *Registry) GetFileRestoring(ctx, hash string) (ShardFileInfo, error)` and
  `func (r *Registry) GetXorbInfoRestoring(ctx, hash string, rebuild func() ([]byte, error)) ([]byte, error)`:
  on `kv.ErrNotFound`, `Restore(..., claimOrphan=false)` and read again; otherwise return the
  original not-found.

    `Restored`, `GetFile` returns the original record, parked key gone.
  - `TestRestoreKeepsNewerLiveValue`: park a footer, `PutXorbInfo` a different value,
    `Restore` → live value unchanged, parked key gone.
  - `TestDeleteParkedLosesToRestoring` and `TestRestoreLosesToDeleting`: put the parked key

  - `TestDeleteParkedRemovesObjectThenKey`: `removeObject` called once, key gone; a

  - `TestRestoreFinishesRestoringKey`: key left in `restoring` with data → `Restore` writes
    the live key and removes the parked one.
  - `TestRestoreClaimsOrphanXorb`: no live footer, no parked key, `claimOrphan=true` →

### Task 3: The sweep

**Files:**
- Modify: `pkg/xet/gc/gc.go` (replace `DryRun`), `pkg/xet/gc/xorbs.go`
  (`ListXorbsFromWalker` sets `Mtime` and `Size`), `pkg/xet/gc/gc_test.go`,
  `pkg/xet/gc/xorbs_test.go`
- Create: `pkg/xet/store/lock.go` (+ test in `parked_test.go` or `lock_test.go`)

**Interfaces — Consumes:** Task 1.
**Produces:**
- `XorbRef{Prefix, Hash string; Size int64; Mtime time.Time}`.
- `type Item struct { Hash string; Bytes int64 }`.
- `type Params struct { Registry *xetstore.Registry; ScanBatchSize int; RepoExists func(ctx, repo string) (bool, error); ListXorbs func(ctx) ([]XorbRef, error); RemoveXorb func(ctx, hash string) error; StoredFooter func(ctx, hash string) ([]byte, error); FileMinAge, XorbMinAge time.Duration; Now func() time.Time; DryRun bool }`.
- `type Report struct { DryRun bool; StaleRefs []xetstore.FileRef; Finished, FilesRestored, FilesDeleted, FilesParked, XorbsRestored, XorbsDeleted, XorbsParked, OrphansParked []Item; Errors []string }` (JSON snake_case tags).
- `func Sweep(ctx, params Params) (Report, error)` — steps 1–9 of the spec in order; a
  per-item failure is appended to `Errors` and the run continues; a failed held/used scan or
  xorb listing returns an error.
- `func (r *Registry) AcquireGCLock(ctx, now time.Time, ttl time.Duration) (release func(context.Context) error, err error)`
  — key `xet/gc/lock`, value = expiry unix seconds; create-only, or take over an expired one
  with `SetIf`; `ErrGCLocked` otherwise. `Sweep` takes it with ttl 6h unless `DryRun`.
